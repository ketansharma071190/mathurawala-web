The round, in one line

Two ways in: a ₹2 Cr lean round, anchored toward a $2M scale round.

₹2 Cr proves the model (outlets + central kitchen, ~₹5.5 Cr ARR). $2M builds the scale engine (a factory + packaging line + D2C + diaspora) toward the ₹50 Cr+ trajectory. Structure flexible (equity / CCD / SPV / revenue-share), founder-controlled. We do not lead with a valuation; we let demand set it.

How we run it

Warm first, time-boxed, and a little unforgettable.

  1. Map warm paths from the founder's network (YC, APAC, Simplifai) to Tier A and B, intros first.
  2. A tight, time-boxed process so interest clusters and competition sets the terms.
  3. The deck, a one-page teaser, and a data room (PetPooja exports + the ARR bridge + P&L) ready to send.
  4. A creative edge no SaaS founder has: we can ship the pitch, a Mathura tasting box, and let an investor taste home. (Full playbook in the raise strategy.)
Note for the table: this is the prepared map, not a contact dump. Before any outreach we validate each fund's current partner, stage and thesis, and find the warmest path in. Named firms are real and consumer-active; fit and timing get confirmed per name.
